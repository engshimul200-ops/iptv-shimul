# SHIMUL BARAL TV

**Developed and Managed by SHIMUL BARAL**

## একটি পেশাদার বাংলা IPTV এবং লাইভ টিভি অ্যাপ্লিকেশন

বিশ্বের যেকোনো প্রান্ত থেকে লাইভ টিভি চ্যানেল এবং খেলাধুলা সরাসরি দেখুন।

### বৈশিষ্ট্য

✅ **লাইভ টিভি চ্যানেল**
- বাংলাদেশের সব জনপ্রিয় চ্যানেল
- আন্তর্জাতিক টিভি চ্যানেল
- উচ্চ মানের স্ট্রিমিং (720p, 1080p)

✅ **খেলাধুলা**
- বিশ্বকাপ ফুটবল ২০२६ লাইভ
- ক্রিকেট লাইভ
- টেনিস, বাস্কেটবল, হকি এবং আরও অনেক কিছু
- বিশ্বের সব দেশের খেলার চ্যানেল

✅ **ব্যবহারকারী বান্ধব ইন্টারফেস**
- সম্পূর্ণ বাংলা ভাষায়
- গাঢ় থিম (Dark Theme)
- মসৃণ অ্যানিমেশন
- দ্রুত এবং প্রতিক্রিয়াশীল

✅ **অতিরিক্ত বৈশিষ্ট্য**
- চ্যানেল সার্চ
- ক্যাটাগরি ফিল্টার
- পছন্দের চ্যানেল সংরক্ষণ
- দেখার ইতিহাস
- নোটিফিকেশন সাপোর্ট
- ব্যবহারকারী প্রোফাইল

### প্রযুক্তি

- **ফ্রেমওয়ার্ক:** Flutter
- **ব্যাকএন্ড:** Firebase (Authentication, Firestore, Storage)
- **ভিডিও প্লেয়ার:** Video Player + Chewie + Better Player
- **স্ট্রিমিং:** HLS & Adaptive Streaming Support
- **স্টেট ম্যানেজমেন্ট:** Provider
- **নেভিগেশন:** Go Router

### স্ক্রিন সেকশন

1. **হোম (Home)** - হাইলাইটেড চ্যানেল এবং সামপ্রতিক
2. **লাইভ টিভি (Live TV)** - সব টিভি চ্যানেল
3. **খেলাধুলা (Sports)** - সব খেলার চ্যানেল
4. **সংবাদ (News)** - সংবাদ চ্যানেল
5. **বিনোদন (Entertainment)** - বিনোদন চ্যানেল
6. **পছন্দের চ্যানেল (Favorites)** - সংরক্ষিত প্রিয় চ্যানেল
7. **সময়সূচী (Schedule)** - চ্যানেল সিডিউল
8. **সেটিংস (Settings)** - অ্যাপ সেটিংস
9. **আমাদের সম্পর্কে (About)** - অ্যাপ তথ্য

### ইনস্টলেশন

```bash
# ফ্লাটার ডাউনলোড করুন
flutter pub get

# অ্যাপ চালান
flutter run
```
